## Ce que tu dois faire dans app.html

### PORTAIL DIASPORA (expéditeur)
1. Formulaire d'envoi :
   - Nom complet
   - Numéro de téléphone (format international)
   - Montant à envoyer (USD/EUR/GBP/CAD)
   - Calcul automatique : montant reçu en XOF avec frais 0.8%

2. Flux OTP :
   - Clic sur "Envoyer" → appel POST /api/auth/send-otp avec le numéro
   - Affichage champ OTP 6 chiffres
   - Vérification → POST /api/auth/verify-otp
   - Si OTP validé → POST /api/transfer/send

3. Écran de confirmation :
   - ID de transaction (généré ou retourné par l'API)
   - Montant envoyé, frais, montant reçu en XOF
   - Statut : "En cours de traitement"

### PORTAIL BÉNIN (destinataire)
1. Recherche de transfert :
   - Input numéro de téléphone du destinataire
   - Clic → GET /api/transfer/:phone ou GET /api/transfer/:id
   - Affichage : nom envoyeur, montant XOF, statut (badge coloré)

2. Retrait Mobile Money :
   - Bouton "Retirer"
   - Modal : choix MTN MoMo / Moov Money
   - Input numéro Mobile Money
   - Confirmation → POST /api/withdraw
   - Écran succès avec numéro de référence

## Connexion backend

Les endpoints backend sont dans le repo (fichiers backend/). 
Base URL à utiliser : crée une variable const API_BASE en haut du JS.

Endpoints attendus :
* POST /api/auth/send-otp
* POST /api/auth/verify-otp  
* POST /api/transfer/send
* GET /api/transfer/:id
* GET /api/rates
* POST /api/withdraw

⚠️ IMPORTANT : Si un endpoint backend ne répond pas ou n'est pas déployé,
utilise des mocks réalistes avec un délai simulé (setTimeout 1200ms) pour 
que TOUT soit démontrable sans serveur actif. L'app doit marcher en demo 
même hors ligne.

Exemple de mock :
async function sendOTP(phone) {
  // Essaie l'API réelle, fallback sur mock
  try {
    const res = await fetch(`${API_BASE}/api/auth/send-otp`, {...})
    if (!res.ok) throw new Error()
    return await res.json()
  } catch {
    await delay(1200)
    return { success: true, message: "OTP envoyé (simulation)" }
  }
}
